## 현재 흐름에서 발견한 문제와 변경

- 3열 화면의 항해사 목록은 자동 맞춤을 하려는 사람에게 불필요한 상시 공간을 차지했다. 목표와 선박의 2열로 바꾸고 빈 선실을 누르면 그 자리에 배치할 항해사 목록을 연다. 모바일은 목표가 먼저 나온다.
- 보유 필터가 수동 목록에 붙어 있어 계산 후보를 바꾼다는 사실이 잘 드러나지 않았다. 목표 상단으로 옮기고 전체/보유 몇 명 중 계산하는지 표시한다.
- 목표 레벨 변경은 삭제와 재등록이 필요했다. 각 목표에서 직접 수정한다. 적용 범위와 현재 수치, 부족분은 계속 보인다.
- 계산 결과가 긴 상태 문장으로만 표시됐다. 목표별 현재/추천/부족 비교표와 선박별 추천 명단·장착 효과를 추가했다. 사용자가 적용하기 전에는 현재 배치를 변경하지 않는다.
- 잘못 바꾼 보유 정보, 목표, 배치를 복구하기 어려웠다. 현재 탭에서 최근 20회 변경을 되돌릴 수 있게 했다. 새로고침 후에는 변경 이력을 유지하지 않는다.
- 목록은 효과/기술 검색, 이름순/등급순 정렬, 상태별 인원, 검색·필터 초기화를 추가했다.

## 확인 범위

기존 계산 규칙 테스트와 빌드 외에 브라우저에서 선실 선택 배치, 되돌리기, 목표 직접 수정, 검색과 필터, 계산 결과 비교/적용, 모바일 레이아웃을 확인했다. 테스트 배치에서 목표 달성 4/5 → 5/5, 승선 24 → 29명 비교와 적용 후 24명 복구를 확인했고, 효과 검색 15명 및 초기화 642명, 보유 체크 후 되돌리기까지 확인했다. 최적화 알고리즘과 데이터 범위는 변경하지 않는다.

## 다음 평가에서 볼 점

처음 사용하는 사람이 보유 항해사 등록 → 목표 추가 → 추천 결과 적용까지 설명 없이 완료하는지 관찰한다. 목표 수정 시 재등록을 시도하는지, 전체 항해사 계산과 보유 제한을 구별하는지, 부족 목표를 보고 다음 행동을 결정하는지도 확인한다. 실제 사용자 검증 전에는 클릭 수 감소 외에 시간 절감이나 성공률 향상을 단정하지 않는다.
