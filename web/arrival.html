대기캡처 상태

캡처와 감지

대기 중
  1. 게임을 창 모드(또는 테두리 없는 창)로 두세요. 전체화면 전용 모드는 캡처되지 않아요.
  2. 캡처 시작을 누르고 창 목록에서 Uncharted Waters Origin을 고르세요.
  3. 이 탭을 닫지 말고 다른 일을 하세요. 도착 화면이 보이면 알람음이 울리고, 설정해 두면 디스코드로도 메시지가 가요.

캡처를 시작하면 게임 화면이 여기에 보여요

아직 검사한 화면이 없어요.

게임 창을 최소화하면 캡처가 멈출 수 있어요. 다른 창으로 가려지는 건 괜찮아요. 캡처 영상은 이 브라우저 안에서만 처리되고 어디로도 전송되지 않아요.

최근 감지 기록
  • 아직 감지된 도착이 없어요.
스크린샷으로 감지 테스트

게임 스크린샷 파일을 고르면 같은 감지 계산을 돌려 유사도를 보여줘요. 도착 화면은 임계값보다 높고, 항해·세계지도 화면은 낮게 나와야 정상이에요.

알림 설정

감지 기준

도착 화면은 보통 0.85~1.00, 항해나 다른 메뉴는 0.55 이하로 나와요. 오탐이 있으면 올리고, 놓치면 내리세요.

알람음

디스코드

디스코드 채널 설정 → 연동 → 웹훅에서 만든 주소예요. 이 브라우저에만 저장되고 메시지를 보낼 때만 디스코드로 전송돼요.

{place}는 도시·마을, {time}은 감지 시각으로 바뀌어요. 휴대폰 알림을 받으려면 <@사용자ID>로 자신을 멘션하세요.

항로 · 대항해시대 오리진 팬 도구PC 크롬·엣지에서 동작 · 영상은 브라우저 밖으로 나가지 않아요

감지 방식

캡처한 게임 화면의 좌상단에서 도착 화면의 제목 글자 모양을 찾아요. 도시는 "도시 / 입항 중입니다." 로딩 화면, 마을은 로딩 없이 뜨는 마을 창의 "〈 마을 ?" 제목이 기준이에요.

글자 자리가 밝은 비율에서 글자 바깥이 밝은 비율을 뺀 값을 유사도로 쓰기 때문에 배경 그림이나 시간대와 무관하고, 창 크기와 UI 배율 90~110%에서 확인했어요. 임계값을 넘는 화면이 두 번 이어지거나 한 번이라도 확실하게 넘으면 알리고, 같은 도착은 설정한 시간 동안 다시 알리지 않아요.

캡처 영상, 웹훅 주소, 설정은 모두 이 브라우저 안에만 있어요. 서버로 보내는 데이터는 없고, 디스코드 메시지만 사용자가 입력한 웹훅으로 전송돼요.
