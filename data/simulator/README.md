# 공개 시뮬레이터 데이터

추가 반영: 멜라티(S·교역·방적상), 제임스 랭커스터(S·모험·갑판장).
`supplement.json`에 공개 Firestore 원본과 갱신·조회 시각을 보존했다.
기본 스냅샷 640명에 두 명을 더한 현재 카탈로그는 642명이다.
두 명의 스탯 12종, 효과 11개씩(3차 초월 포함), 기술 2개씩을 추가했다.
원본의 LV2를 보존했으며 모든 효과·기술은 기존 정의와 연결된다.
아래 640명 수치는 최초 정적 스냅샷 추출 기록이다.

출처: [UWO Fleet Simulator by Astraeus](https://uwo-fleet-simulator.web.app/).
페이지 버전 `260913_1137`, 공개 정적 데이터에 기재된 생성 시각은 2026-09-02 11:11 UTC.
실시간 Firestore 데이터가 아닌 사이트 자체의 공개 폴백 스냅샷을 가져왔다.

## 파일

- `catalog.sqlite`: 항해사, 스탯, 효과·기술, 레벨별 값, 직업 효과를 저장한 SQLite DB.
- `catalog.json`: 같은 정보를 웹에서 읽을 수 있게 내보낸 파일.
- `comparison.json`: 엑셀 DB와의 차이 전체 및 누락·충돌 목록.
- `manifest.json`: 출처 URL, 버전, 원본 파일별 SHA-256, 추출 시각.

원본 파일은 `../site-source/`에 보존했다. 가져온 JavaScript는 실행하지 않았으며,
데이터 리터럴을 JSON으로 파싱했다. `scripts/import_simulator.py`로 재생성할 수 있다.
이전 엑셀 DB인 `../navigators.sqlite` 및 `../navigators.json`은 변경하지 않았다.

## 추출 결과

항해사 640명, 스탯 7,680개, 효과 정의 526종, 기술 정의 104종,
항해사별 효과 연결 6,655개, 기술 연결 1,322개.
태생 효과, 언어, 고용 조건, 제독 명령도 제공된 범위에서 항해사 상세에 보존했다.
직업별 직접 수치 효과는 52개 직업에 대해 저장했다.

엑셀의 634명 모두 존재하며 해당 인물의 등급·타입·직업·스탯은 전부 일치한다.
추가 항해사는 루이즈 드보주아외, 마진 루즈, 발렌티나 모렐, 안토니오 말라테스타,
자코모 데캄파니아, 헬렌 라즈베리 6명이다.
효과 칸 225개와 기술 칸 5개가 변경됐다. 여기에는 엑셀에 없던 3차 초월 효과 칸도 포함된다.
효과 정의 수와 항해사가 실제 보유한 효과 이름 수는 서로 다른 집계다.

## 자동 맞춤 설계에 활용할 수 있는 정보

- 효과·기술마다 1~10레벨 값표가 있다. 일부 값은 비어 있으므로 채워진 것으로 취급하면 안 된다.
- 참고 사이트는 LV 표기가 없으면 1, LV2라면 2를 더한다. 이 규칙을 `level_basis`로 명시했다.
- 참고 사이트는 레벨 합계가 10을 넘으면 값표 조회를 10으로 제한한다.
- `value_cap_raw`는 퍼센트 등 실제 결과 수치의 상한이다. 효과 레벨 상한과 다른 항목이다.
- `category`는 모험/교역/전투 분류, `aggregation_scope`는 fleet/ship 적용 범위다.
- 태생·직업의 직접 수치는 효과 중첩 레벨과 다른 데이터로 보존했다.
- 슬롯마다 습득 레벨, 잠재/인연/3차 초월을 구별했다. 보유와 활성화는 별개이며 `active`는 NULL이다.

## 정확한 최적화 전 남은 확인

사용자 확인 규칙은 `../game-rules.json`에 보존하고 DB/JSON에도 포함했다.
잠재 효과는 선택하여 장착하며 후보 전체를 자동 활성화하지 않는다.
잠재 칸은 일반 항해사 5칸, 제독 6칸이다. 원본의 S+ 등급은 제독을 나타낸다.
3차 초월 효과는 항해사별 고정된 전용 칸이고 3차 초월 완료 시 활성화된다.
각 연결의 `activation_rule`에 이를 반영했다. 원본의 잠재 효과 1·2 열은 후보 데이터의
위치이며, 실제 장착 슬롯 두 개를 의미하는 것으로 해석하지 않는다.

1. 참고 사이트 `js/core.js`는 모든 보유 효과를 합산하고 활성 효과 선택을 모델링하지 않는다고 명시한다.
   잠재 칸 수는 사용자 확인에 따라 일반 항해사 5칸, 제독 6칸을 적용한다.
   3차 초월 효과는 잠재 칸과 별도의 고정 칸에서 활성화된다.
2. 노련한/능숙한 노 젓기는 분류가 모험이고 참고 계산기는 선단 합산하지만,
   설명과 엑셀에는 승선한 갤리류 선박에 적용된다고 나온다. 실제 적용 범위는 NULL로 보류했다.
3. `투쟁적인`, `돌격`, `교전 기술`은 항해사 보유 목록에는 있으나 정의가 없다.
   임의 삭제하거나 다른 효과로 합치지 않고 `missing_definition`으로 남겼다.
4. 일부 레벨별 수치가 비어 있다. SQLite는 NULL, JSON 원문 배열은 원래 빈 문자열을 보존한다.
   정확한 목록은 `comparison.json`의 `incomplete_level_values`에 있다.
5. 스탯 성장 기준은 여전히 미확인이다. 참고 사이트 순위 보정계수를 실제 스탯 성장 공식으로 쓰지 않았다.
6. 태생 중복 제거, 직업 효과 합산 및 기술 합산은 참고 코드에서 확인되지만 실제 게임 검증은 별도다.

추출 검증: SQLite 무결성 및 외래 키, 이름 중복, 전체 스탯 필드와 숫자 형식,
원본의 모든 비어 있지 않은 효과·기술 칸 수를 대조했다. 미확인 값은 0으로 바꾸지 않았다.
